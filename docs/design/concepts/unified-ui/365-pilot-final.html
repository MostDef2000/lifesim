#365 · сквозной пилот · волна 2

Мир → магазин → явное «Идти» → покупка → образ → возврат

Кликабельная финальная версия пилота: один непрерывный сценарий с честными отказами. Выбор POI не двигает героя; перемещение — только явным действием; покупка и надетость — только после ответа мира; возврат — обратным путём, без телепортации. Сессия активна по умолчанию: герой под управлением игрока, ИИ лишь предлагает пожелание — принять, отложить или проигнорировать, без штрафов и блокировки команд.

Клик-сквозной сценарий

Проходите шаги в кадре. Журнал под кадром фиксирует ответы мира, отказы и проигнорированные устаревшие ответы.

      Проверяемые правила: клик по магазину не двигает героя; «Идти» — отдельное подтверждённое действие; отказ не меняет баланс и вещи; при Flux off текстовый контекст и действия остаются; уход во время ожидания делает поздний ответ устаревшим; возврат — обратный путь, а не телепорт. Пожелание ИИ — только предложение: игнорирование не блокирует команды и не снижает показатели; пока сессия активна, новых действий без согласия игрока нет, а после её завершения герой продолжает жить самостоятельно.

      Что демонстрирует пилот

    • Happy path — выбор магазина, явное перемещение, покупка куртки, надевание, возврат домой.
    • Отказ — сценарий «Мало денег»: цена выше баланса, мир отказывает, инвентарь и баланс не меняются.
    • Flux unavailable — иллюстрация заменяется текстовым контекстом, действия доступны.
    • Пожелание ИИ — ненавязчивый пузырь над героем; «Принять» ставит обычную проверяемую команду, «Отложить» и «Действую сам» скрывают пожелание без штрафа; ручные команды не блокируются.
    • Stale-ответ — уход во время ожидания: поздний ответ игнорируется и не мутирует состояние.
    • Без телепортации — возврат идёт обратным путём, герой оказывается там, откуда вышел.
