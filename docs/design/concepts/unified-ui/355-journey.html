Из дома в магазин за курткой

Один маршрут в пяти кадрах. Каждый шаг различает запрос, подтверждение, ожидание, завершение и отказ. Навигация не выполняет действие, покупка и надетость появляются только по ответу мира, отказ при нехватке денег ничего не подтверждает, а возврат идёт через «в пути», без телепортации.

Сториборд

Выберите шаг слева и выполните действие. Статусы request → accepted → active → completed либо refused — серверные: интерфейс показывает их по ответу и не мутирует мир оптимистично.

Проверяйте: «Недостаточно средств» даёт отказ без вещи и без списания; «Flux недоступен» не подтверждает предпросмотр и не блокирует проверенное действие; возврат показывает «в пути» и не перескакивает домой мгновенно; двойное нажатие не создаёт второй запрос.

Правила состояний

Один и тот же набор статусов на каждом шаге, без «магического» успеха.

Запрос request

  • кнопка блокируется на время запроса;
  • показанные данные прежние;
  • второй клик не отправляет второй запрос;
  • ответ привязан к сессии и шагу.

Ожидание accepted · active

  • accepted — мир принял запрос;
  • active — действие выполняется (в пути, обработка);
  • это ещё не результат;
  • отмена — отдельное действие, если поддерживается.

Завершение completed

  • прибытие подтверждено;
  • вещь получена и списание подтверждено;
  • надетость подтверждена;
  • только здесь меняются данные.

Отказ refused

  • недостаточно средств — вещь не выдана, деньги не списаны;
  • Flux недоступен — предпросмотр не создан, факт не подменяется;
  • игрок остаётся там же, где был;
  • повтор — явное действие.
Пример приёмки. Дано: 1 000 ₽, куртка 880 ₽. Когда игрок покупает, тогда после подтверждения баланс 120 ₽, вещь в инвентаре. Когда денег 500 ₽, тогда отказ: баланс прежний, вещи нет. Когда Flux недоступен, тогда предпросмотр не создан, но надеть уже полученную вещь можно только по подтверждению мира.
