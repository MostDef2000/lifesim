Шестнадцать экранов, девять пунктов, одна карта

Предварительная информационная архитектура игрока: все 16 статических экранов, динамическое Место, три уровня детализации внутри Мира и правила панель / модальное окно / полный экран. Интерактивная карта показывает родителя, слой и поведение «Назад» для каждого экрана.

Канон: §27, §27.1 Основа: #363 component sheet Маршруты: backend/app/web/app.js, реестр routes Part 1/3: #364 · #366 · #365
Граница артефакта. Это design handoff, а не изменение кода и не игровой факт. Суммы, имена и адреса — условные демонстрационные данные. Палитра, типографика, радиусы и spacing взяты из §27; новых визуальных направлений не вводится. Админ-экран #/admin намеренно не входит в карту игрока (16 экранов без него).
Композиция:
Выбор экрана — локальный просмотр, маршрут и герой не меняются.

Карта экранов

Слева — полный список игрока. Выбор карточки показывает, к какому пункту навигации относится экран, каким слоем он открывается и что сохраняется при возврате. Внутри Мира переключаются три LOD; выбор LOD не является перемещением героя.

Родитель и «Назад». Подчинённые экраны (Дом, Карьера, Журнал, Настройки, Внешние сервисы) не занимают отдельный пункт навигации: они открываются из родителя и возвращают туда же, подсвечивая родительский пункт.
  • 9 пунктов — Мир, Чат, Люди, Инвентарь, Рынок, Дела, Цель, Профиль, Образ.
  • 16 экранов — login, create, world, chat, people, inventory, shop, tasks, desire, profile, appearance, external, home, career, events, settings.
  • +1 динамический — #/location/:id, Место внутри контекста Мира.
  • LOD 1–3 — три уровня детализации карты Мира, не отдельные маршруты.

Панель, модальное окно, полный экран

Три слоя решают разные задачи. Ни один из них не подтверждает игровое действие без ответа мира.

Панель panel

Контекст выбранного объекта у края экрана: POI, предмет, человек, цель.

  • не меняет маршрут; мир остаётся видимым;
  • закрывается Esc / кликом по миру, возвращает к тому же состоянию;
  • одна панель за раз; новая заменяет содержимое, не наслаивается;
  • сохраняет выбор, фильтр и черновик в родительском экране.

Модальное окно modal

Блокирующее решение: подтвердить покупку, принять цель, завершить диалог.

  • фокус-ловушка, Esc = отмена, один основной и один отменяющий выход;
  • не открывается поверх другого модального окна;
  • кнопка не выглядит выполненной; статус — только после ответа мира;
  • отмена не мутирует инвентарь, баланс и отношения.

Полный экран full

Маршрут или крупный экран: Мир, Место, системные экраны, вход и создание героя.

  • только по явному переходу; не открывается случайно из панели;
  • адрес отражает экран; «Назад» возвращает на родителя;
  • контекст героя, времени и режима остаётся видимым;
  • вход и создание героя — без рейла навигации.
Запрет подмены факта. Смена экрана, выбор POI или нажатие кнопки не объявляют покупку, перемещение или действие выполненными. Результат приходит из мира, а интерфейс лишь показывает ожидание и затем подтверждение либо отказ.

Три сквозных потока

Пошаговый просмотр: какой экран, какой слой, что происходит и что сохраняется к возврату.

    Шаги демонстрируют порядок экранов и слоёв. Ни один шаг не выполняет серверное действие.

    Возврат назад сохраняет состояние

      Выбор места не перемещает героя

      Явное правило: клик по POI меняет только выбор и контекст панели. Позиция героя меняется лишь после подтверждённого перемещения.

      Перемещение героя возможно только действием «Идти» в экране Места и только после ответа мира.

      Порядок слоёв

      1. Клик по POI → панель с выбором, герой стоит
      2. «Открыть место» → полный экран #/location/:id
      3. «Идти» → модальное подтверждение → ожидание → прибытие
      4. «Назад» → Мир с прежним POI, но без телепортации
      Честность. Если перемещение не подтверждено, герой остаётся на месте, а экран показывает отказ — не «успех».
