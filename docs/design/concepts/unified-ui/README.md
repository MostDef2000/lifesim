# Единый UI/UX — предварительные макеты v1

Продолжение [Nordic Coastal Village](../nordic-coastal/README.md), #353, #363, #364. Все 18 бордов используют «Тёплый вечер», общий визуальный контекст, девять действующих пунктов навигации и единые компоненты. Доигровая ветка без внутриигрового HUD. Каждый SVG содержит desktop 1440×900 и mobile 390×844 в одном листе. Векторные портреты, предметы, архитектура, цены, имена и состояния — условные эскизы, не замена утверждённым ассетам и не игровые факты. Иллюстрация места использует существующий предварительный Core Village reference, не точный фасад каждого POI. Экраны требуют отдельных визуальных итераций и сверки функций с production, особенно mobile. Статические макеты не реализуют действия.

[Кликабельный пилот #365](365-pilot.html) — скачать и открыть локально. Выбор/осмотр без перемещения, явный MOVE, имитированное прибытие, pending/ответ покупки, отказ без изменения баланса/вещи, экипировка и отказ, Flux off, возврат без телепортации. Автономный режим в fixture блокирует ручные команды до явной смены режима; действующие возможности других режимов уточняются по игре. Не настоящий сервер. JS-сценарии проверены в симулированном DOM, не в реальном браузере. Не полный #390.

Порядок #353 сохранён: upstream эталоны → макеты → пилот → атлас → отдельная реализация. Новые версии макетов требуют согласования и проверки desktop/mobile, keyboard/focus, применимых состояний, реальных объектов и маршрутов. Не закрывать задачи по факту наличия изображения.

## Волна 1: интерактивные артефакты #363 / #387 / #354

Предварительные концепты, **не утверждённые production-ассеты**; приёмка владельца ожидается.
Это design handoff, не код и не игровые факты.

- [#363 — component sheet](363-component-sheet.html) — self-contained HTML: девять пунктов навигации, постоянный контекст героя, desktop 1440×900 и mobile 390×844, матрица состояний, keyboard/focus, карточка POI с четырьмя условными иллюстрациями.
- [#363 — UI-токены](363-design-tokens.md) — палитра §27, типографика, spacing 4/8/12/20/28, радиусы 12/8, тени, иконки, цели ≥44px; сверка кремовой оболочки мира с тёмными legacy-экранами и список test-pinned литералов.
- [#387 — архитектурный board](../nordic-coastal/387-architecture-board.html) — master board, эталоны жилого и хозяйственного здания, материалы, фасады/интерьерные anchors, силуэты, шаблон паспорта POI, дневной и вечерний кадр.
- [#354 — контракт кадра](../nordic-coastal/354-frame-contract.html) — актуальный кадр, исторический снимок, Flux недоступен и неизвестные данные; время наблюдения, честный fallback, переходы и правило «изображение не подтверждает действие».

## Design batch 2 — интерактивные макеты (#364/#366/#365/#372/#357/#355/#373/#394/#386)

Предварительные концепты, **не утверждённые production-ассеты**; приёмка владельца ожидается.
Это design handoff, не код и не игровые факты. Все файлы self-contained: скачать и открыть в браузере.

- [#364 — навигация](364-navigation.html) — информационная архитектура: шестнадцать экранов на девяти пунктах, desktop/mobile, переходы и состояния пунктов без изменения мира.
- [#366 — инвентарь](366-items.html) — эталонный системный экран: грамматика панелей, категории, карточки предметов и состояния выбранного/надетого.
- [#365 — пилот, финальная версия](365-pilot-final.html) — сквозной сценарий дом → магазин → явное «Идти» → покупка → образ → возврат без телепортации.
- [#372 — образ](372-appearance.html) — фактическая одежда отдельно от предпросмотра; надеть/снять только после ответа мира, отказ и чужая сессия не применяются.
- [#357 — идентичность жителя](../nordic-coastal/357-identity.html) — один житель в разных обстоятельствах: одежда и состояние по подтверждённым данным. Борд #357 лежит отдельно — `unified-ui/357-identity.svg`, а интерактивный HTML — в `nordic-coastal/`.
- [#355 — путь](355-journey.html) — путь героя из дома в магазин за курткой: шаги, ожидание и честные состояния на общих компонентах.
- [#373 — рынок](373-market.html) — витрина с ценой, остатком и доступностью; lifecycle запрос → принят → идёт → готово, отказ при нехватке средств, загрузка и черновик продажи; деньги и вещи меняются только после подтверждения.
- [#394 — место](394-place.html) — осмотр POI не двигает героя; явный переход только к подтверждённо доступному месту, текущее место против выбранного, подтверждённые участники, время/погода и честный Flux-fallback.
- [#386 — язык предметов](../nordic-coastal/386-item-language.html) — куртка, сапоги, шапка, один тип еды и воды: общий масштаб, нейтральный свет, один образ на инвентарь/рынок/сцену, состояния «в наличии / надето / выбрано / изображение недоступно».
