# #363 · UI-токены «Северный остров — Тёплый вечер»

> **ПРЕДВАРИТЕЛЬНЫЙ КОНЦЕПТ, НЕ УТВЕРЖДЁННЫЙ PRODUCTION-АССЕТ.**
> Issue #363 · design handoff, не изменение кода и не игровой факт.
> Канон направления: `docs/VISUAL-BIBLE.md` §27 и §27.1. Токены ниже не вводят новую палитру
> и не заменяют текущие значения в `backend/app/web/style.css`.

## 1. Назначение и границы

Документ фиксирует **один канонический набор** для новых и мигрируемых экранов: цвет, типографику,
spacing, радиусы, тени, иконки и минимальные цели. Он объясняет, как соотносятся между собой
кремовая оболочка мира и тёмные legacy-оболочки, найденные в аудите UI.

Это design handoff:

- значения взяты из §27/§27.1 и уже существующих токенов `.game-shell` / `.world-shell`;
- ни один файл кода, теста или конфигурации этим документом не меняется;
- перечисленные ниже test-pinned литералы **нельзя менять в коде** без отдельной
  implementation-задачи и осознанного обновления тестов;
- документ не объявляет макет принятым и не закрывает issue.

### 2.2 Типографика

Источник: §27 «Typography». Семейства и насыщенность не меняются.

| Роль | Значение | Применение | Источник |
|---|---|---|---|
| Крупный заголовок | `Georgia, "Times New Roman", serif`, вес 400 | заголовки экранов и панелей; serif только для крупного | §27; `.game-shell h1…h3` |
| Текст и действия | `system-ui, -apple-system, "Segoe UI", sans-serif`, `16px/1.55` | основной текст, кнопки, поля | §27; `.game-shell` |
| Числа | sans с `font-variant-numeric: tabular-nums` | need-бары, деньги, время, счётчики | §27 |
| Мета | 14px, `--dim` | подписи под заголовком, статус действия | `.game-header-meta`, `.game-status` |
| Мелкий текст | 12px, `--dim` | примечания, бейджи, подписи полей | `.settings-note`, бейджи |
| Микро-подпись | 11px, uppercase, letter-spacing | служебные метки, пресеты | `.settings-preset-mark` |

Размеры 14/12/11 — наблюдаемая иерархия текущего UI, а не новые семейства. Новые экраны
начинаются с 16px/1.55 и используют меньшие размеры только для вторичной информации.

| Категория | Значение | Применение | Источник |
|---|---|---|---|
| Spacing | `4 / 8 / 12 / 20 / 28 px` | внутренние отступы, gap, вертикальный ритм | §27 «Layout philosophy» |
| Радиус панели | `12px` | карточки, контекстная панель, статус-панели | §27 |
| Радиус контрола | `8px` | кнопки, поля, небольшие карточки | §27 |
| Тень панели | `0 12px 32px rgba(48, 39, 31, 0.16), 0 2px 8px rgba(48, 39, 31, 0.10)` | плавающая панель/карточка | `.world-shell --w-shadow-panel` |

`.game-shell` сегодня не объявляет собственных теней; канонические значения берутся из
`.world-shell` как существующий визуальный референс. Это не новый токен и не повод добавлять
третью шкалу теней.

### 2.4 Иконки и цели

| Параметр | Значение | Источник |
|---|---|---|
| Сетка | 24×24 px | §27 «Icon language» |
| Штрих | 1.75px, скруглённые соединения и концы | §27 |
| Размеры | 20px и 24px | §27 |
| Метафоры | дверь, чашка, сумка, разговор, тропа | §27 |
| Минимальная цель | ≥ 44×44 px | §27; `.game-action min-height: 44px`; WCAG 2.5.8 |

Иконка вторична по отношению к тексту там, где смысл неочевиден. Декоративные рамки, гербы,
металлические панели и fantasy-HUD не используются (§16).

### 2.5 Движение

- Анимация объясняет изменение состояния: переход, появление, progress, подтверждение, выбор.
- Постоянное декоративное движение ради «живости» не используется (§17).
- `prefers-reduced-motion: reduce` отключает длительные анимации; настройка принадлежит #383,
  но новые компоненты обязаны её уважать.
- Загрузка показывается спиннером/скелетоном, а не подменой текста на «готово».

## 6. Как применять

- Новый экран: `class="game-shell"` (или его будущий эквивалент), палитра через `--game-*`,
  spacing 4/8/12/20/28, радиусы 12/8, цель ≥44px, `:focus-visible` обязателен.
- Мир/карта: `.world-shell` уже несёт §27; не дублировать палитру локальными hex-литералами.
- Локальный POI: меняет сцену, материалы и иллюстрацию, **не** UI-тему, не палитру и не
  типографику (§27.1).
- Тёмные и provisional-оболочки: не копировать их литералы в новые компоненты. Это миграционный
  долг, а не второй канон.
- Значения из §5 не трогать в коде до отдельной задачи.
