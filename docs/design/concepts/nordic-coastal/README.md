## Волна 1: интерактивные артефакты #363 / #387 / #354

Предварительные концепты, **не утверждённые production-ассеты**; приёмка владельца ожидается.
Это design handoff, не код и не игровые факты.

- [#387 — архитектурный board](387-architecture-board.html) — self-contained HTML: master board, эталоны жилого и хозяйственного здания, материалы, фасады/интерьерные anchors, силуэтная схема, шаблон паспорта POI, день и вечер. Core Village доминирует; Neo-punk/Historic/Weathered — сочетабельные акценты; география и локации не меняются.
- [#354 — контракт кадра](354-frame-contract.html) — self-contained HTML: актуальный кадр, исторический снимок, Flux недоступен и неизвестные данные; время наблюдения на каждом кадре, рабочий fallback, набор переходов, сверка с #356 и #387.
- [#363 — component sheet](../unified-ui/363-component-sheet.html) — интерактивный лист компонентов: навигация, контекст героя, состояния, focus, desktop/mobile.
- [#363 — UI-токены](../unified-ui/363-design-tokens.md) — канонический набор §27 и сверка с legacy-оболочками; test-pinned литералы не меняются в коде.
