## Волна 1: интерактивные артефакты #363 / #387 / #354

Предварительные концепты, **не утверждённые production-ассеты**; приёмка владельца ожидается.
Это design handoff, не код и не игровые факты.

- [#387 — архитектурный board](387-architecture-board.html) — self-contained HTML: master board, эталоны жилого и хозяйственного здания, материалы, фасады/интерьерные anchors, силуэтная схема, шаблон паспорта POI, день и вечер. Core Village доминирует; Neo-punk/Historic/Weathered — сочетабельные акценты; география и локации не меняются.
- [#354 — контракт кадра](354-frame-contract.html) — self-contained HTML: актуальный кадр, исторический снимок, Flux недоступен и неизвестные данные; время наблюдения на каждом кадре, рабочий fallback, набор переходов, сверка с #356 и #387.
- [#363 — component sheet](../unified-ui/363-component-sheet.html) — интерактивный лист компонентов: навигация, контекст героя, состояния, focus, desktop/mobile.
- [#363 — UI-токены](../unified-ui/363-design-tokens.md) — канонический набор §27 и сверка с legacy-оболочками; test-pinned литералы не меняются в коде.

## Design batch 2 — интерактивные макеты (#364/#366/#365/#372/#357/#355/#373/#394/#386)

Предварительные концепты, **не утверждённые production-ассеты**; приёмка владельца ожидается.
Это design handoff, не код и не игровые факты. Все файлы self-contained: скачать и открыть в браузере.

- [#364 — навигация](../unified-ui/364-navigation.html) — информационная архитектура: шестнадцать экранов на девяти пунктах, desktop/mobile, переходы и состояния пунктов без изменения мира.
- [#366 — инвентарь](../unified-ui/366-items.html) — эталонный системный экран: грамматика панелей, категории, карточки предметов и состояния выбранного/надетого.
- [#365 — пилот, финальная версия](../unified-ui/365-pilot-final.html) — сквозной сценарий дом → магазин → явное «Идти» → покупка → образ → возврат без телепортации.
- [#372 — образ](../unified-ui/372-appearance.html) — фактическая одежда отдельно от предпросмотра; надеть/снять только после ответа мира, отказ и чужая сессия не применяются.
- [#357 — идентичность жителя](357-identity.html) — один житель в разных обстоятельствах: одежда и состояние по подтверждённым данным. Векторный борд #357 лежит в `unified-ui/357-identity.svg`, а интерактивный HTML — здесь, в `nordic-coastal/`.
- [#355 — путь](../unified-ui/355-journey.html) — путь героя из дома в магазин за курткой: шаги, ожидание и честные состояния на общих компонентах.
- [#373 — рынок](../unified-ui/373-market.html) — витрина с ценой, остатком и доступностью; lifecycle запрос → принят → идёт → готово, отказ при нехватке средств, загрузка и черновик продажи; деньги и вещи меняются только после подтверждения.
- [#394 — место](../unified-ui/394-place.html) — осмотр POI не двигает героя; явный переход только к подтверждённо доступному месту, текущее место против выбранного, подтверждённые участники, время/погода и честный Flux-fallback.
- [#386 — язык предметов](386-item-language.html) — куртка, сапоги, шапка, один тип еды и воды: общий масштаб, нейтральный свет, один образ на инвентарь/рынок/сцену, состояния «в наличии / надето / выбрано / изображение недоступно».
