Один образ вещи — один язык состояний

Опорный лист личных предметов: куртка, сапоги, шапка, один тип еды и один тип воды. Нейтральный свет, общий масштаб, читаемый силуэт и никакого HUD внутри предмета. Одна и та же иллюстрация используется в инвентаре, на рынке и в сцене; состояния «в наличии / надето / выбрано / изображение недоступно» показаны только там, где они есть.

Лист

Кликните предмет, чтобы увидеть его в трёх поверхностях. Надетость показывается только у одежды; у еды и воды её нет — там честно указано «расходуемый». Недоступное изображение — пунктирная рамка с подписью, а не выдуманная картинка.

Главное правило. Иконка никогда не обещает неизвестный цвет, материал или состояние. Цвет, ткань и износ — свойства конкретного экземпляра из данных; пиктограмма обозначает только тип вещи.

Правила, которым следует лист

Пять типов, общий масштаб и четыре состояния — без декоративного HUD внутри предмета.

Один образ reuse

  • одна иллюстрация на инвентарь, рынок и сцену;
  • общий масштаб и нейтральный свет;
  • силуэт читается без подписи;
  • никакого HUD, цены или кнопок внутри предмета.

Честные состояния state

  • «надето» — только у одежды;
  • «выбрано» — рамка, а не смена цвета вещи;
  • «в наличии» — по данным остатка;
  • у еды и воды надетости не существует.

Неизвестное unknown

  • изображение недоступно — пунктир и подпись;
  • цвет и материал не угадываются;
  • износ показывается числом/подписью из данных;
  • нейтральный символ типа вместо фантазии.

Тип и экземпляр type

  • food_bread и water_bottle — типы;
  • цена, количество и состояние — экземпляр;
  • состояние не рисуется в пиктограмме;
  • неизвестный экземпляр не получает выдуманный вид.
Пример приёмки. Дано: куртка в запасе. Когда её надевают, тогда появляется подпись «надето», а сама пиктограмма не меняет цвет или материал. Когда изображение недоступно, тогда вместо арта показывается пунктирная рамка с подписью типа. Когда открыт хлеб, тогда состояния «надето» нет — есть «расходуемый» и остаток.
