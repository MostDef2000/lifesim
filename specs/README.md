# Specifications

Significant changes live under `specs/<feature>/` with three artifacts:

- `spec.md`: outcome, scope, requirements, NFRs, and acceptance evidence.
- `plan.md`: current behavior, design, change map, risks, and test strategy.
- `tasks.md`: executable work, traceability, verification, and Definition of Done.

Use the templates in `.specify/templates/overrides/` and keep artifacts synchronized with the accepted implementation.
